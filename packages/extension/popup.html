Welcome

Open any webpage, say what you want done, and TabHandoff runs it through your local AI bridge — with honest status if nothing is configured.

  1. Right-click a page → Hand off with TabHandoff
  2. Answer What do you want done?
  3. Run with AI (local bridge) — ZIP export stays optional

Start the desktop app or pnpm bridge, paste the token in Settings, and set a free/local provider (Ollama) or an API key in the bridge environment.
