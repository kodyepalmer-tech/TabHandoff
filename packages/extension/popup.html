Hand off coding / AI-chat work — not a Transfer app.

Welcome

Inside ChatGPT, Claude, or Cursor web: highlight a prompt (or its message), choose Hand this off to another AI, then download a package or continue on this computer when a local destination is available.

  1. Load this extension unpacked in Chrome / Edge / Brave
  2. Open an AI chat → highlight text → right-click Hand off selection to another AI
  3. Pick Download handoff (upload later) or Continue now (local bridge)

The desktop Transfer screen is supporting infrastructure. AI site DOMs change — capture is best-effort and labeled fragile when we climb to a parent message.
