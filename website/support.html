Support

TabHandoff is open source. Help lives in the setup guide and GitHub Issues — there is no separate support portal yet.

Start here

  • First-run setup — desktop → Load unpacked → Run with AI; ZIP optional; CWS / Pages / domain not live yet
  • Downloads — desktop installers appear only when a GitHub Release asset exists
  • Privacy policy — capture, processing, retention

Common fixes

  • Can’t Run with AI — Start desktop/bridge, paste the token in extension Settings. ZIP-only still works without a token.
  • Bridge: off — Fine for optional ZIP download. Needed for AI execution and My Activity / history sync.
  • Can’t hand off chrome:// — Open a normal https:// page.
  • No screenshot — Some pages block capture; URL + text still hand off.
  • Desktop “Coming soon” — No published installer for that OS yet. Use pnpm install && pnpm build && pnpm desktop.
  • Store install missing — Chrome Web Store is not live; use Load unpacked only.
