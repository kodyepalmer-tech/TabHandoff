Common fixes

  • Store install missing — Chrome Web Store is not live; use Load unpacked only.
  • Can’t hand off chrome:// — Open a normal https:// page.
  • Validation / continuation — Use CLI validate / verify-continuation; don’t claim a handoff continued without a passing check.
  • Bridge / Run with AI — Optional infrastructure. Start desktop/bridge + token only if you need loopback.
  • Desktop “Coming soon” — No published installer for that OS yet. Use from-source setup.
