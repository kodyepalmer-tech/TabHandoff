Privacy Policy

What is captured, where it is processed, and how long it stays on your machine. Written for everyday users and Chrome Web Store reviewers.

Last updated: 2026-10-29 · Markdown source: docs/privacy.md

TabHandoff helps you hand a browser task to AI that runs on your computer (or a provider endpoint you configure), then keeps the result in local history. A portable ZIP is optional for sharing. There is no TabHandoff cloud account required for the core path.

Summary

  • Captured: page URL/title, your instruction, optional selected text, optional visible-tab screenshot.
  • Processed: on this machine via the local bridge (127.0.0.1) and your chosen AI (local model or API key that stays on the bridge process — not in the extension).
  • Retained: under ~/.tabhandoff/ until you delete it. No automatic cloud sync.
  • Shared: only when you export a ZIP, copy a brief, or send files yourself.
  • We do not sell personal data or use page content for advertising.

Data the extension may access

Data Purpose
Active tab URL and title Identify the page for the task / package
Selected text Include context you chose
Visible-tab screenshot Evidence when Chrome allows capture
Your instruction Tell the local AI (or next person) what to do
Local bridge token Authenticate to the loopback helper on your machine
AI task history (local) Show past runs and results in desktop / extension history

Permissions

  • activeTab / scripting — read the page you hand off
  • contextMenus — right-click Hand off
  • storage — onboarding, optional bridge settings, local history cache
  • http://127.0.0.1/* — talk only to the local bridge

Where processing happens

  • Extension ↔ bridge traffic stays on loopback (127.0.0.1 with a token you paste.
  • Local models (for example Ollama) run on your computer.
  • If you set a cloud provider API key on the bridge/CLI process, that provider receives the prompt/context you chose — still never via a TabHandoff server, and keys are not stored in the extension or ZIP.

Retention

Tasks, receipts, screenshots, and bridge config live under ~/.tabhandoff/ (or TABHANDOFF_HOME) on this device. Uninstalling the desktop app does not automatically delete that folder. Delete the folder yourself to erase local history.

What we do not collect

No page cookies or passwords are copied into packages by design. No TabHandoff cloud sync of browsing history. No advertising SDK in the extension MVP.

Sharing

Optional ZIP download and “copy brief” put content under your control. Treat captured page text as untrusted (it may contain prompt-injection text).

Children

TabHandoff is not directed at children under 13.

Contact

Use GitHub issues or see Support. After Pages + DNS, this page is the stable HTTPS privacy URL for Chrome Web Store submission (https://tabhandoff.com/privacy.html). That hostname is not live until the founder enables Pages and DNS.
