Privacy Policy

How the TabHandoff browser extension handles data. Written for Chrome Web Store reviewers and everyday users.

Last updated: 2026-10-29 · Markdown source: docs/privacy.md

TabHandoff creates a portable handoff package from a webpage you choose. By default the package is downloaded as a ZIP on your device. There is no TabHandoff cloud account required for that path.

Summary

  • Captured data: page URL/title, optional selection, optional screenshot, your instruction.
  • Default: local ZIP download only — not uploaded to TabHandoff servers.
  • Optional: save to a local bridge on 127.0.0.1 with a token you paste.
  • We do not sell personal data or use page content for advertising.

Data the extension may access

Data Purpose
Active tab URL and title Identify the page in the package
Selected text Include context you chose
Visible-tab screenshot Evidence when Chrome allows capture
Your instruction Tell the next person or AI what to do
Local bridge token (optional) Authenticate to the loopback helper on your machine

Permissions

  • activeTab / scripting — read the page you hand off
  • contextMenus — right-click Hand off
  • storage — onboarding + optional bridge settings
  • http://127.0.0.1/* — optional local bridge only

What we do not collect

No page cookies or passwords are copied into packages by design. No TabHandoff cloud sync of browsing history. No advertising SDK in the extension MVP.

Sharing

If you download a ZIP or copy a brief for another AI, you control who receives it. Treat captured page content as untrusted data.

Children

TabHandoff is not directed at children under 13.

Contact

Use the TabHandoff GitHub issues. For install help see Support. After the public site ships, this page is the stable HTTPS privacy URL for Chrome Web Store submission (https://tabhandoff.com/privacy.html). That hostname is not live until the founder enables Pages + DNS.
