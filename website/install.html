Setup

Coding-agent handoffs: capture from the browser, export a portable package, continue in the next agent. Desktop and local bridge are optional tools.

Chrome Web Store and signed installers are not live. File/desktop capture and “any agent anywhere” are roadmap — not shipped.

Today

  1. Node 22+, then: 
    git clone https://github.com/kodyepalmer-tech/TabHandoff.git
cd TabHandoff
pnpm install && pnpm build
  2. Load unpacked packages/extension in Chrome, Edge, or Brave (chrome://extensions → Developer mode).
  3. Hand off a normal https page → Save package. Validate / continue with the CLI — see verified-handoff.md.

Honest status: “package created” is not “agent finished.” Continuation needs a real verify step.

Optional tools

pnpm desktop or pnpm bridge for loopback runs and local history. Not required for Save package.

Installers

Download only enables buttons when a GitHub Release asset exists. Early builds would be unsigned.

Troubleshooting

  • Can’t hand off chrome:// — use a normal website.
  • Bridge off — fine for ZIP-only packages.
