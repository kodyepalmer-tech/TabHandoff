Setup & troubleshoot

First run: desktop → Load unpacked → Run with AI. ZIP is optional. This page does not invent a live store, installer, or tabhandoff.com site until those exist.

Not live yet: Chrome Web Store · signed installers · GitHub Pages / tabhandoff.com (founder enables those). Use the from-source path below today.

First run (today)

  1. Install Node.js 22+, then: 
    git clone https://github.com/kodyepalmer-tech/TabHandoff.git
cd TabHandoff
pnpm install && pnpm build
pnpm desktop
    Optional: install Ollama, pull a model with its full tag, leave it running. Copy the access token.
  2. Chrome / Edge / Brave → chrome://extensions → Developer mode → Load unpacked → packages/extension → Settings → paste token.
  3. Open a normal https://… page → Hand off → Run with AI. History stays in ~/.tabhandoff/. Optional: also download a ZIP to share.

Status stays honest: if the bridge or model is missing, you get unavailable / failed / package-only — never a fake “agent finished.”

Longer checklist: docs/extension-setup.md · Privacy

Optional: ZIP-only

Without desktop, Save package still downloads a ZIP. That path creates a package — it does not mean an agent ran.

Desktop installers (when published)

Buttons on Download appear only when a GitHub Release asset exists. Early builds are unsigned (Gatekeeper / SmartScreen). No v* release is published yet.

  • macOS · Windows · Linux

macOS

  1. Download the .dmg from GitHub Releases when present.
  2. Drag TabHandoff to Applications.
  3. If Gatekeeper blocks: System Settings → Privacy & Security → Open Anyway, or right-click → Open.

Windows

  1. Download the NSIS .exe (x64) when present.
  2. If SmartScreen appears: More info → Run anyway only for the official Release asset.

Linux

chmod +x TabHandoff-*-linux-*.AppImage
./TabHandoff-*-linux-*.AppImage
# or: sudo apt install ./TabHandoff-*-linux-amd64.deb

Where data lives

  • macOS / Linux: ~/.tabhandoff/
  • Windows: %USERPROFILE%\.tabhandoff\
  • Override: TABHANDOFF_HOME

Troubleshooting

  • Can’t Run with AI: start pnpm desktop, paste token; confirm Ollama/model tag if using a local model.
  • Port in use: quit the other TabHandoff window, or edit ~/.tabhandoff/bridge.json.
  • chrome:// pages: use a normal website.
  • Download “Coming soon”: no installer for that OS yet — use from-source above.
  • More: docs/troubleshooting.md · Support
