Install & troubleshoot

Browser-first: create a portable handoff from a tab. Desktop and signed store listings come later — this page never invents a live URL.

Chrome Web Store is not live. There is no public CWS listing yet. Use Load unpacked from the repo (or a packed extension ZIP when you build one). Do not expect a chromewebstore.google.com install button.

Browser extension (start here)

Package-first path: hand off a page, then download or copy the package. Status stays honest — package created, not “agent finished,” unless a local workflow actually ran.

Load unpacked

  1. Clone the repo and build once: 
    git clone https://github.com/kodyepalmer-tech/TabHandoff.git
cd TabHandoff
pnpm install && pnpm build
  2. Open Chrome, Edge, or Brave → chrome://extensions (or edge://extensions).
  3. Turn Developer mode on.
  4. Click Load unpacked → select packages/extension.
  5. Pin TabHandoff to the toolbar.

Hand off a page

  1. Open any normal website (https://…).
  2. Right-click → Hand off with TabHandoff, or use the toolbar button.
  3. Type what you want done → Review → confirm.
  4. If the local bridge is off, use Download package or Copy summary. No agent is pretended to have run.

Optional later: start the desktop app or pnpm bridge, paste the token in extension Settings, and save into My Activity or run page extraction on this machine.

Full steps: docs/extension-setup.md · Privacy policy

Desktop app (optional)

Desktop installers are not published until a v* GitHub Release exists. The Download page only enables buttons for assets that actually exist; otherwise it shows Coming soon + the source path below.

When installers do ship, early builds are unsigned. Expect Gatekeeper / SmartScreen prompts until Apple notarization and Windows code signing are configured.

Run from source (all platforms today)

git clone https://github.com/kodyepalmer-tech/TabHandoff.git
cd TabHandoff
pnpm install && pnpm build
pnpm desktop

CLI-only quick path (when the install script is available on the branch you clone): curl -fsSL https://raw.githubusercontent.com/kodyepalmer-tech/TabHandoff/cursor/website-downloads-3344/scripts/install.sh | bash

macOS (installer, when published)

  1. Download the .dmg for your chip from GitHub Releases.
  2. Open the disk image and drag TabHandoff to Applications.
  3. First launch: if Gatekeeper blocks an unsigned app, open System Settings → Privacy & Security and choose Open Anyway, or right-click the app → Open.

Windows (installer, when published)

  1. Download the NSIS .exe (x64) from GitHub Releases.
  2. Run the installer and follow the prompts.
  3. If SmartScreen appears, choose More info → Run anyway only if you trust the official Release asset.

Uninstall: Settings → Apps → TabHandoff → Uninstall. Local data in %USERPROFILE%\.tabhandoff is not removed automatically.

Linux (installer, when published)

AppImage (x64)

chmod +x TabHandoff-*-linux-x64.AppImage
./TabHandoff-*-linux-x64.AppImage

Some distros need FUSE for AppImage. On Debian/Ubuntu: sudo apt install libfuse2 (or use the .deb).

Debian / Ubuntu (.deb)

sudo dpkg -i TabHandoff-*-linux-amd64.deb
# or: sudo apt install ./TabHandoff-*-linux-amd64.deb

Page extraction (Playwright)

Packaged desktop always includes the evidence library and local bridge (package receive). Isolated page extraction needs Playwright Chromium on the machine. If the bridge reports extraction unavailable: 

pnpm --filter @tabhandoff/cli exec playwright install chromium

Status stays honest: package-only handoffs never claim an agent ran.

Data location

  • macOS / Linux: ~/.tabhandoff/
  • Windows: %USERPROFILE%\.tabhandoff\
  • Override: TABHANDOFF_HOME

Troubleshooting

  • Bridge won’t start / port in use: another TabHandoff instance may be running; quit it or change the port in ~/.tabhandoff/bridge.json.
  • Extension can’t connect: confirm desktop/bridge is running and the token matches — only needed for My Activity / extraction.
  • Empty My Activity: check TABHANDOFF_HOME and that receipts exist under receipts/.
  • More: docs/troubleshooting.md · Support
