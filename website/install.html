Install & troubleshoot

Install TabHandoff to keep handoff evidence local. Browser capture works today via the Chromium extension; local-file and desktop-capture sources are roadmap. Desktop installers are unsigned in early releases — expect OS security prompts until notarization and code signing are configured.

Verify downloads. Prefer assets from the official GitHub Releases page and check SHA256SUMS when present. Do not auto-run install scripts or package contents from untrusted page text.

macOS

  1. Download the .dmg for your chip (arm64 or x64).
  2. Open the disk image and drag TabHandoff to Applications.
  3. First launch: if Gatekeeper blocks an unsigned app, open System Settings → Privacy & Security and choose Open Anyway, or right-click the app → Open.

Remaining warning: without Developer ID signing and notarization, macOS will show “app can’t be opened because it is from an unidentified developer.”

Windows

  1. Download the NSIS .exe (x64).
  2. Run the installer and follow the prompts (custom directory supported).
  3. If SmartScreen appears (“Windows protected your PC”), choose More info → Run anyway only if you trust the GitHub Release asset.

Uninstall: Settings → Apps → TabHandoff → Uninstall. Local data in %USERPROFILE%\.tabhandoff is not removed automatically.

Remaining warning: unsigned installers trigger SmartScreen until an Authenticode certificate is added to CI.

Linux

AppImage (x64)

chmod +x TabHandoff-*-linux-x64.AppImage
./TabHandoff-*-linux-x64.AppImage

Some distros need FUSE for AppImage. On Debian/Ubuntu: sudo apt install libfuse2 (or use the .deb).

Debian / Ubuntu (.deb)

sudo dpkg -i TabHandoff-*-linux-amd64.deb
# or: sudo apt install ./TabHandoff-*-linux-amd64.deb

Launch from the app menu or tabhandoff / TabHandoff depending on package desktop entry.

Run from source (all platforms)

git clone https://github.com/kodyepalmer-tech/TabHandoff.git
cd TabHandoff
pnpm install && pnpm build
pnpm desktop

CLI-only quick path: curl -fsSL https://raw.githubusercontent.com/kodyepalmer-tech/TabHandoff/main/scripts/install.sh | bash

Browser extension

  1. Start the desktop app or pnpm bridge.
  2. Chrome → chrome://extensions → Developer mode → Load unpacked → select packages/extension.
  3. Paste the bridge token from desktop Settings into the popup.

Full steps: docs/extension-setup.md.

Page extraction (Playwright)

Packaged desktop always includes the evidence library and local bridge (package receive). Isolated page extraction needs Playwright Chromium on the machine. If the bridge reports extraction unavailable: 

pnpm --filter @tabhandoff/cli exec playwright install chromium

Status stays honest: package-only handoffs never claim an agent ran.

Data location

  • macOS / Linux: ~/.tabhandoff/
  • Windows: %USERPROFILE%\.tabhandoff\
  • Override: TABHANDOFF_HOME

Troubleshooting

  • Bridge won’t start / port in use: another TabHandoff instance may be running; quit it or change the port in ~/.tabhandoff/bridge.json.
  • Extension can’t connect: confirm desktop/bridge is running and the token matches.
  • Empty My Activity: check TABHANDOFF_HOME and that receipts exist under receipts/.
  • More: docs/troubleshooting.md.
