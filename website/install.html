Setup & troubleshoot

Primary path today: capture from the browser → portable package → continue in a coding agent (CLI / MCP). Local bridge and desktop are supporting tools — not the product pitch.

Not live yet: Chrome Web Store · signed desktop installers · “any agent anywhere” · file/desktop capture. Roadmap items are labeled below — do not treat them as shipped.

First run (coding-agent handoff)

  1. Install Node.js 22+, then: 
    git clone https://github.com/kodyepalmer-tech/TabHandoff.git
cd TabHandoff
pnpm install && pnpm build
  2. Browser capture (ships today): Chrome / Edge / Brave → chrome://extensions → Developer mode → Load unpacked → packages/extension. Hand off a normal https://… page → Review → Save package (portable ZIP) or connect the optional local bridge for loopback runs.
  3. Continue in a coding agent: validate / continue / verify with the CLI (or MCP). See docs/verified-handoff.md. 
    node packages/cli/dist/index.js validate /path/to/package
node packages/cli/dist/index.js create-verified --url https://example.com --instruction "Summarize next steps"

Status stays honest: package-created is not “agent finished”; continuation checks must pass before you claim a handoff continued.

Browser extension

Chrome Web Store is not live. Load unpacked is the path until the founder publishes a listing. Pin the toolbar icon; open a normal website (not chrome://).

Checklist: docs/extension-setup.md · Privacy

Supporting tools (optional)

Desktop app / pnpm bridge / local run-ai help with loopback execution and history. Useful — not the beachhead story. Example: 

pnpm desktop   # optional local bridge + activity
# paste token in extension Settings only if you need loopback

Desktop installers

Buttons on Download appear only when a GitHub Release asset exists. Early builds would be unsigned. No v* release is required to use the coding-agent CLI path from source.

  • macOS — .dmg when published; Gatekeeper may warn if unsigned.
  • Windows — NSIS .exe when published; SmartScreen may warn if unsigned.
  • Linux — AppImage / .deb when published.

Roadmap (not shipped)

  • File and desktop capture
  • One-click install via Chrome Web Store / signed installers
  • Broader “any agent anywhere” beyond coding agents

Where data lives

  • macOS / Linux: ~/.tabhandoff/
  • Windows: %USERPROFILE%\.tabhandoff\
  • Override: TABHANDOFF_HOME

Troubleshooting

  • Can’t hand off chrome://: use a normal https page.
  • Bridge / Run with AI: optional; start pnpm desktop or pnpm bridge and paste the token only if you need loopback.
  • Validation fails: re-export the package; check schema docs for 0.1 vs verified 0.2.
  • More: docs/troubleshooting.md · Support
