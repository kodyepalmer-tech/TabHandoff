How it works

Primary path: local AI on your machine. Status stays honest — TabHandoff never pretends an agent ran when only a package was created.

  1. 01 · Connect

    Local AI + desktop

    Run the TabHandoff desktop app (or local bridge). Point it at a free local model (for example Ollama) or a provider key that stays on this computer — never in the browser extension.

  2. 02 · Task

    Hand off from the browser

    Open a normal webpage, describe what you want done, and run with AI through the local bridge. The extension is the capture surface; execution happens on your machine.

  3. 03 · History

    Real result, saved locally

    Completed and failed tasks land in local history under ~/.tabhandoff/. Optional: also download a portable ZIP when you want to share context — ZIP is not required for the primary path.

How you install today

Chrome Web Store and signed desktop installers are not live yet. We do not invent store buttons or download links for missing assets.

  • Desktop from source — pnpm install && pnpm build && pnpm desktop (installers appear on GitHub Releases only after a published v* tag).
  • Browser extension — Load unpacked from packages/extension (developer path until CWS).
  • Optional ZIP — Save a portable package when you want to share; not required for Run with AI / history.

Local-first. No mandatory cloud.

Page context and AI results stay on your machine unless you export or share them. Full policy: Privacy.

  • Captured: page URL/title, your instruction, optional selection and screenshot.
  • Processed on 127.0.0.1 via the local bridge / your chosen AI provider endpoint — not a TabHandoff cloud.
  • Retained under ~/.tabhandoff/ until you delete it.
  • Cookies, passwords, and authenticated browser state are not copied into packages by design.
