How it works

Three steps. No cookie clone. Status is always honest — TabHandoff never pretends an agent ran when only a package was created.

  1. 01 · Capture

    Hand off a tab

    Right-click in Chrome, Edge, or Brave. Add an instruction and optional selection. Chrome Web Store listing is not live yet — load unpacked from the repo today.

  2. 02 · Package

    Portable context

    TabHandoff builds a versioned handoff: URL, task, metadata, and permitted evidence — ready for another agent or human.

  3. 03 · Continue

    Pick up anywhere

    Share the package or paste a brief into another AI. Optional local bridge / desktop adds My Activity and page extraction on your machine.

Built for compatible AI agents

TabHandoff is an open handoff protocol. Agents can consume a package, continue the work, and return a result with an execution receipt.

  • Validate and read packages via CLI or MCP (handoff_validate / handoff_read).
  • Create, continue, export, and attach evidence with stable handoff IDs.
  • Distinguishes verified actions from agent-reported summaries — hashes stay honest.

Local-first. No mandatory cloud.

Core functionality never requires uploading your page content. Full policy: Privacy.

  • Default: download a package on this device — no TabHandoff cloud account.
  • Optional local bridge on 127.0.0.1 with a token you paste (~/.tabhandoff/).
  • Cookies, credentials, and authenticated browser state are not transferred by default.
  • No telemetry or advertising SDK in the extension MVP.
