TabHandoff

Hand off any work. Pick up anywhere.

A universal handoff layer for work and AI agents. Capture context, package it, and let the next person — or the next AI — continue with proof that stays on your machine. The browser is one capture source.

How it works

Three steps. No cookie clone. Status is always honest — TabHandoff never pretends an agent ran when only a package was created.

  1. 01 · Capture

    Start from a source

    Today: right-click a browser tab in Chrome, Edge, or Brave — or pass a URL to the CLI. Add an instruction and optional selection. Files and desktop capture are on the roadmap.

  2. 02 · Package

    Portable context

    TabHandoff builds a versioned handoff: sources, task, metadata, and permitted evidence — ready for another agent or human.

  3. 03 · Continue

    Pick up anywhere

    Run page extraction locally, continue from the CLI or MCP, and keep receipts in the desktop evidence library.

Built for compatible AI agents

TabHandoff is an open handoff protocol for work. Agents can consume a package, continue the work, and return a result with an execution receipt.

  • Validate and read packages via CLI or MCP (handoff_validate / handoff_read).
  • Create, continue, export, and attach evidence with stable handoff IDs.
  • Distinguishes verified actions from agent-reported summaries — hashes stay honest.

Local-first. No mandatory cloud.

Core functionality never requires uploading captured content.

  • Default store: ~/.tabhandoff/ on this machine (override with TABHANDOFF_HOME).
  • Receipts, screenshots, bridge token, and jobs stay local.
  • Cookies, credentials, and authenticated browser state are not transferred by default. File and screen capture will require explicit permission when those sources ship.
  • No telemetry or background upload of captured content.
